#  Plataforma de Educación Virtual - Bit Criollo

Bienvenidos al repositorio de la **Plataforma de Educación Virtual - Bit Criollo**, un proyecto desarrollado para facilitar el proceso de aprendizaje mediante un entorno virtual donde estudiantes, docentes, coordinadores y administradores pueden interactuar de acuerdo con sus roles.

##  ¿Qué es Bit Criollo?

Bit Criollo es una plataforma educativa que busca centralizar diferentes actividades académicas en un solo lugar.

La plataforma permite gestionar cursos, usuarios, inscripciones, lecciones, recursos educativos, tareas y exámenes, brindando a cada usuario las funcionalidades correspondientes según su rol.

##  Objetivo del proyecto

El objetivo principal es desarrollar una plataforma educativa funcional, organizada y segura que permita:

*  Gestionar estudiantes y sus cursos.
*  Administrar docentes y contenidos.
*  Crear y gestionar cursos.
*  Realizar actividades académicas.
*  Compartir recursos educativos.
*  Manejar usuarios y permisos de acuerdo con sus roles.

##  Roles de usuario

La plataforma cuenta con diferentes tipos de usuarios:

*  **Estudiante:** puede consultar cursos, inscribirse y realizar actividades.
*  **Docente:** puede crear y administrar contenidos de sus cursos.
*  **Coordinador:** participa en la gestión académica de la plataforma.
*  **Administrador:** administra usuarios y diferentes aspectos del sistema.

##  Tecnologías utilizadas

El proyecto está desarrollado principalmente con:

**Java 17 · Spring Boot · Spring Security · PostgreSQL · JPA / Hibernate · JWT · Maven**

Para las pruebas y validación de los servicios se utilizará:

**Postman**

##  Organización del proyecto

El repositorio estará organizado en diferentes secciones para facilitar el desarrollo y la documentación del proyecto.

*  **Main:** versión principal y desarrollo de la plataforma.
*  **Pruebas:** pruebas de los servicios del backend utilizando Postman.
*  **Desarrollo:** archivos y avances relacionados con el desarrollo de la plataforma.

##  Estado del proyecto

El proyecto se encuentra en proceso de desarrollo. Las diferentes funcionalidades se irán integrando y validando progresivamente hasta completar la plataforma.
